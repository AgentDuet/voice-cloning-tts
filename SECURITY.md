# Security policy

## Reporting a vulnerability

Please do not report security problems in a public issue or pull request.

Report them privately, in either of these ways:

- **On GitHub:** the repository's **Security** tab › **Report a vulnerability**.
- **By email:** **security@b3networks.com**.

Please include what you found, the version or commit, and the steps to reproduce it. We will
acknowledge your report, keep you informed while we fix it, and credit you when the fix is
released, unless you would rather not be named.

## Supported versions

Fixes go into the latest release. Please check that a problem still happens there before you
report it.
